# AGENTS.md — chandu-weds-divya

## Project

Single-page wedding invitation website (Chandu weds Divya, Nov 26 2026). Built with Vite + React 18 + TypeScript + shadcn-ui + Tailwind CSS. Generated by [Lovable](https://lovable.dev).

## Commands

| Task | Command |
|---|---|
| Dev server (port 8080) | `npm run dev` |
| Production build | `npm run build` |
| Lint | `npm run lint` |
| Unit tests | `npm run test` (single run) / `npm run test:watch` |
| Preview build | `npm run preview` |

No `typecheck` script is defined. Run `npx tsc --noEmit` manually if needed.

Package manager: **npm** (`package-lock.json` is committed; `bun.lock` is also present but npm is primary).

## Architecture

- **Entry point**: `src/main.tsx` → `src/App.tsx` → `src/pages/Index.tsx`
- **Routing**: react-router-dom with only two routes: `/` (Index) and catch-all `*` (NotFound). The app is effectively a single-page scroll experience.
- **Layout**: Full-viewport scroll-snap sections wrapped in `<SnapSection>` with variants (`fade`, `slide`, `flip`). No navigation bar — sections scroll vertically.
- **Bilingual**: `LanguageContext` provides English (`en`) / Telugu (`te`) toggle. All UI strings live in the `t()` translation function in `src/components/wedding/LanguageContext.tsx`. Add new keys there.
- **Audio**: Background Nadaswaram music via `MusicToggle` component (`public/nadaswaram.mp3`).
- **Path alias**: `@` → `./src` (configured in vite, vitest, and tsconfig).

## Directory layout

```
src/
  components/ui/       # shadcn-ui primitives (auto-generated, do not hand-edit)
  components/wedding/  # app-specific sections and features
  pages/               # route-level components (Index, NotFound)
  hooks/               # custom hooks (use-mobile, use-toast)
  lib/utils.ts         # cn() className merge utility
  test/                # vitest setup
  assets/              # images (mandala, gopuram, ganesh, wedding-bg)
```

## Testing

- **Unit**: Vitest + `@testing-library/react` with jsdom. Setup in `src/test/setup.ts` (includes `matchMedia` mock). Tests go in `src/**/*.{test,spec}.{ts,tsx}`.
- **E2E**: Playwright via `lovable-agent-playwright-config`. Use `test`/`expect` re-exported from `playwright-fixture.ts`.
- No running services or fixtures required for tests.

## Tooling quirks

- **TypeScript**: `strictNullChecks: false`, `noUnusedLocals: false`, `noUnusedParameters: false`, `noImplicitAny: false`. The project is intentionally lenient.
- **ESLint**: `@typescript-eslint/no-unused-vars` is disabled. `react-refresh/only-export-components` is warn-level.
- **lovable-tagger**: Vite plugin active only in dev mode; adds Lovable inspector hooks. Safe to ignore.
- **shadcn-ui**: Components in `src/components/ui/` are generated via `components.json` config. New UI components should be added via `npx shadcn@latest add <component>`.
